# P6.2 周预约热力图验收

学生座位页“本周预约热度”、管理员统计中心“预约热力图”进入同一原生GDI页面。可查询任意日期所在完整周；数字表示有效预约，不代表签到。鼠标及方向键选择单元格，显示完整日期、时段、N/40及两位小数利用率；学生仅可导航今天至第六天且尚未开始的时段，伪造消息仍复查时间和角色。

实现复用P4的 `compute_range`，增加显式角色参数，原日报/周报仍固定管理员；新 `stats_compute_heatmap` 允许实际学生/管理员。只向学生发布不含身份的聚合。日序定位整周提取为 `utils_week_start`，P4及热力图共用。每次一次预约加载、一轮计数；继承P4去重索引的排序，未为63格重复读取来源。`heatmap_compute` 投影7×9数量/利用率；`heatmap_level` 严格划分0–8、9–16、17–24、25–32、33–40。电脑表不是历史统计来源，当前故障不改历史数据或固定分母40。

`python tests/test_p6_2.py --cc <gcc>`；build.ps1 -Test、make test-p6-2均已接入。
