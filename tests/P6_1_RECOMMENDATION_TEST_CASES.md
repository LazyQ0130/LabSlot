# P6.1 智能推荐验收

入口：学生座位页“智能推荐”，设置日期、起始时段、连续1–3小时及偏好，刷新前三项，点击候选切回原座位图。推荐只读，不分配编号；本阶段确认预约仍为原一小时时段，连续创建留给独立P6.3阶段。

公式与整数基点、最大连续段、前排位置及当日负载定义见 [设计](../docs/P6_INNOVATION_DESIGN.md)。`BookingAvailability`、`booking_range_mask` 在booking层，避免增加旧独立业务测试的链接依赖；`recommend.h/c` 只使用已验证的可用性快照，不重复读40遍文件。学生身份来自实际会话；新API区分P3维护未完成。旧枚举序号保持，新值追加。

复现：`python tests/test_p6_1.py --cc <gcc路径>`，也接入build.ps1 -Test和make test-p6-1。测试复用原故障注入/原生窗口工具。全部使用新建tests/runs/p6-1-*。

原GUI基础套件的“40 real seat controls / counts”曾因固定总控件数50失败：本阶段新增推荐按钮，真实总数为51。该断言仅将精确期望改为51，并新增要求GUI_SMART_OPEN存在，保留原座位有效/40席空闲条件。没有删除断言或改成宽松的下限判断。其他旧驱动、脚本和断言保持不变。
