## 真实 Windows 缩放与窗口

原系统缩放在 Windows“系统→屏幕”实际读到 **150%（推荐）**，分辨率 **2560×1600**。仅调整缩放，不改分辨率、方向、隐私或安全设置。通过设置界面实际依次切换 **100%→125%→150%**，每次重新启动窗口读到的实际 DPI 分别为 **96、120、144**。最后再次在设置界面确认已恢复原值 **150%（推荐）**，分辨率仍为 **2560×1600**、横向；随后关闭本次打开的设置窗口。

## 端到端与演示复现

新增驱动在完全新建的 tests/runs/p5-4-* 子目录运行，使用实际 Windows 本地日期，预约日期由 `utils_date_add(today,1)` 得到。通过生产窗口的 WM_COMMAND/WM_NOTIFY、日期/组合框、ListView 和实际确认框完成学生注册登录→预约→查看→重复冲突→放弃/确认取消→两条未来预约→中文报告→个人统计→退出；再管理员注册登录→工作台→使用情况→精确学生→报告详情/影响预览→确认故障→历史中取消验证→设备恢复→新增真实预约→日/周统计→放弃/确认导出→退出。
