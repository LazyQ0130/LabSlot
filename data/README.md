# 运行数据目录

首次启动自动创建六个 `.txt` 文件，电脑缺失或零字节时初始化为 40 台正常电脑。

账户文件包含教学明文密码；所有运行 `.txt` 和保存 `.tmp` 均由 `.gitignore` 排除，不提交到 GitHub。需要备份时由使用者单独保存，不能将其视为源码。

测试在独立的 `tests/runs/` 目录运行，不更改此处数据。

P3 维护会按需创建 `maintenance.txt`（未完成意图）、`maintenance.done.txt`（上一条完成意图）以及明确的 `.recovery.txt` 草稿备份。它们也都是运行数据，不提交；备份时应与电脑/预约/报告一起保留。存在未完成意图时先恢复，失败则阻止启动，不补建缺失来源掩盖错误。详见根目录 README。

P4 的 `count.txt` 是管理员显式导出的有序日报快照；正常查询不写统计/账户文件，`Student.time` 仅保留旧缓存兼容。快照会因后续预约变化过时，需重新导出所选日期；写入失败保留旧目标和可能的 `count.txt.tmp` 草稿，由使用者检查保留后重试，不自动删除。详见根目录 README 的13字段格式和限制。
